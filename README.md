# Bluestock Mutual Fund Capstone project

## Project Overview

Bluestock Mutual Fund Analytics is an end-to-end data analytics capstone for
studying the Indian mutual-fund industry. It combines Python, pandas, SQLite,
SQL, Jupyter Notebook, and Power BI to analyze:

- Mutual-fund NAV and historical returns
- Risk metrics such as volatility, Sharpe ratio, and maximum drawdown
- Fund-house assets under management (AUM)
- SIP inflows and category-level market flows
- Investor transactions and geographic trends
- Portfolio holdings and sector exposure
- Fund performance and risk-based recommendations

The project follows this data flow:

```text
Raw CSV data
    -> cleaning and analysis notebooks
    -> processed CSV data
    -> calculated fund metrics
    -> SQLite analytics database
    -> SQL analysis and Power BI dashboard
```

## Setup Instructions

### Prerequisites

- Python 3.10 or newer
- Power BI Desktop for opening the `.pbix` dashboard
- Git, if cloning the repository

### Create the Python Environment

From the project root, create and activate a virtual environment:

```powershell
python -m venv venv
venv\Scripts\Activate.ps1
```

Install the project dependencies:

```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

To confirm that the command-line pipeline is available:

```powershell
python run_pipeline.py --help
```

## Files and Folders

| Path | Description |
| --- | --- |
| `run_pipeline.py` | Master command that calculates metrics, rebuilds SQLite, loads data, and validates SQL |
| `requirements.txt` | Python package dependencies |
| `data/raw/` | Original source CSV datasets |
| `data/processed/` | Cleaned datasets and generated fund metrics |
| `data/db/bluestock_mf.db` | Legacy database used by the original dashboard workflow |
| `data/db/bluestock_mf_pipeline.db` | Database generated by the master pipeline |
| `scripts/compute_metrics.py` | Calculates annualized return, volatility, Sharpe ratio, and drawdown |
| `scripts/run_schema.py` | Creates or resets the canonical SQLite schema |
| `scripts/etl_pipeline.py` | Loads processed CSV files into SQLite |
| `scripts/run_queries.py` | Executes the analytical queries in `sql/queries.sql` |
| `scripts/recommender.py` | Recommends funds for a selected risk grade |
| `scripts/live_nav_fetch.py` | Optionally downloads current NAV history from MF API |
| `sql/schema.sql` | SQLite table definitions, constraints, and indexes |
| `sql/queries.sql` | Dashboard-oriented analytical SQL queries |
| `notebooks/` | Data ingestion, cleaning, EDA, and performance analysis notebooks |
| `dashboard/bluestok_mf_dashboard.pbix` | Power BI dashboard source file |
| `reports/` | Dashboard exports, charts, PDF output, and the data dictionary |

## Run the ETL Pipeline

### Recommended: Run Everything

Run the complete local pipeline from the repository root:

```powershell
python run_pipeline.py
```

This command:

1. Calculates fund-level metrics from cleaned NAV history.
2. Rebuilds `data/db/bluestock_mf_pipeline.db`.
3. Loads all processed datasets into 11 SQLite tables.
4. Runs database integrity and foreign-key checks.
5. Executes and validates all analytical SQL queries.

The default pipeline uses local data and does not require internet access.

### Optional Pipeline Commands

Download fresh NAV history before processing:

```powershell
python run_pipeline.py --fetch-live-nav
```

Run the pipeline and display moderate-risk recommendations:

```powershell
python run_pipeline.py --recommend Moderate
```

Skip analytical SQL validation:

```powershell
python run_pipeline.py --skip-queries
```

### Run ETL Stages Individually

For development or troubleshooting, run each stage in order:

```powershell
python scripts/compute_metrics.py
python scripts/run_schema.py --reset
python scripts/etl_pipeline.py
python scripts/run_queries.py
```

Run the recommender separately:

```powershell
python scripts/recommender.py Moderate
```

## Open the Power BI Dashboard

1. Install and launch Microsoft Power BI Desktop.
2. In Power BI Desktop, select **File > Open report > Browse reports**.
3. Open `dashboard/bluestok_mf_dashboard.pbix`.
4. If Power BI asks for a data-source location, point it to the corresponding
   files inside this repository's `data/` folder.
5. Select **Home > Refresh** to reload the latest available project data.

On Windows, you can also open the dashboard by double-clicking:

```text
dashboard\bluestok_mf_dashboard.pbix
```

If Power BI reports a broken source path after the repository has been moved,
use **File > Options and settings > Data source settings** to update the path,
then refresh the report.

Exported dashboard pages and a PDF preview are available in `reports/` for
users who do not have Power BI Desktop installed.
